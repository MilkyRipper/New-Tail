# New Tail – Coffee Website

A modern coffee shop website designed to showcase coffee products and create an appealing online experience for visitors.

## Features
- Modern and attractive design.
- Coffee product presentation.
- User-friendly interface.
- Responsive layout.

## Technologies Used
- HTML5
- Tailwind CSS

## Project Purpose
This project was built to improve my frontend development skills and gain practical experience creating attractive websites using Tailwind CSS.
